## Required correction — CT-DEV-001R

`placement.ts` applies EPS while updating `worstMargin`. A more negative margin within EPS of the prior value can change the selected joint without updating the stored minimum. This can hide an actual failure when the two margins straddle `-EPS`.

Reproduction against the compiled delivered code:

```typescript
const a = 1.498 + 0.95e-9;
const b = a + 1.196 + 0.5e-9;
evaluatePlacement(
  [{ id: 1, x: a, bottom: 0, skinId: 'default' }],
  b, b - a, undefined, true
);
```

Observed: `ok:true`, safety0, weakestJoint2. Actual debug margins: joint2 `-5.000000413701855e-10` (within tolerance), joint1 `-1.2000000992884452e-9` (fails). Expected: `ok:false`, reason `UNSTABLE_TOWER`, failureJoint1, direction+1, no successful placement. The existing cat alone is stable; this is not invalid prior state.

Correction contract:

- Determine stability from the actual minimum raw margin, updated without EPS suppression: any `sj < -EPS` fails. Passing contacts can never win failure-joint selection.
- Among failed contacts, find the true minimum `sMin`. Choose the lowest joint index among failed contacts whose margin is within EPS of `sMin`. Return that selected contact's actual margin and direction. Use a comparison anchored to the global minimum; pairwise tolerance chains must not drift away from it.
- A second reverse O(k) pass with O(1) extra storage is permitted for deterministic joint selection. No quadratic suffix recomputation or per-frame tower scan. Debug arrays remain optional.
- Passing `safety` is the exact minimum normalized safety; weakest-joint selection uses the lowest passing index within EPS of that minimum. Include the inclusive `sj == -EPS` passing boundary. Selection tolerance must not change the aggregate minimum itself.
- Add regressions for the supplied case and its mirror, exact/near `-EPS` boundaries, both contacts failing within EPS (including a lower-index passing contact near a failure), deterministic joint selection and unchanged inputs. Preserve the 52 existing passing tests and rerun typecheck/tests plus the existing benchmark if traversal changes.

Developer owns the fix. Return changed paths, actual commands/results and any unresolved discrepancy. Stop after this correction; Architect reviews before assigning M2. Existing art verification is a browser-dependent queued task, not a reason to start M2 independently.

## Resolved design questions

1. **Seed0:** accept finite integer seeds, coerce to uint32 as implemented and normalize resulting0 to `0x6d2b79f5`. Snapshot records the normalized seed. Controller normally supplies a uint32. This resolves contradictory nonzero-validation prose in04; no balance change.
2. **MISS_TOP joint:** attempted candidate index `k=cats.length+1`, including1 at the floor. Direction is sign(finalX-supportCenterX), centered tie+1. It marks the attempted contact, not an extra committed cat.
3. **Safety after failure:** retain last committed tower safety and weakest joint. `failure` overrides the normal danger indicator during collapse/results. Failed candidate earns nothing; do not display retained safety as a successful prediction.
4. **Pause counters:** PAUSED retains suspended phaseTicks; `resume` is the authoritative suspended phase/counter pair. Repeated pause cannot overwrite it. Presentation clocks also freeze.
5. **Events/ticks:** each event carries the tick count before that tick's increment; lifecycle events use the current count. A tick that began live counts once even if it enters RESULTS; calls beginning PAUSED/RESULTS do not count. Preserve emitted order and monotonic IDs. Consume typed events, not assumptions that a phaseChanged always precedes/follows every other event. Landing emits placementCommitted before phaseChanged; spawn after settling emits phaseChanged before spawned. No score/persistence write from phaseChanged/resultsReady.
6. **Motion preference changes:** start-time collapse duration is accepted for M1. M4 must support system/user changes: remove nonessential movement immediately and shorten a normal collapse to at most12 further simulation ticks without extending any shorter remainder; retain failure/score/position. If paused, apply to suspended collapse without resuming it. Switching back to full motion must not extend that collapse. Domain adapter contract will be assigned with M4; no unused hook is required now.
7. **Start clears events:** accepted. Controller drains/fans out pending old-run events before replacing a run; then clears old presentation/input generations and drains new spawn events once. Never award progress from a stale run after replacement.
