## Accepted format and mapping

Standalone SVG faces are accepted instead of PNG. No raster exports are required merely because the original table requested PNG. Decode each local SVG as an image, then draw to Canvas 2D with the same transform as its body. Avoid inlining duplicate `clipPath` IDs. If an actual browser decoder/rendering failure remains after correct MIME/local-path handling, retain placeholders and ask Studio for exact 128×128 transparent PNG face exports (and body raster exports only if a body-specific failure exists). No regeneration, paid calls, new styling or physics changes.

- Bodies: source 512×384, logical rect `[48,80,416,416/1.55]` (x,y,width,height), pivot `[256,80+416/1.55]`, all four skins share geometry and mass.
- With logical body width W CSS pixels, body-source scale is `s=W/416`. Draw the complete untrimmed source image at `(pivotScreenX-256s, pivotScreenY-(80+416/1.55)s)` with size `(512s,384s)`.
- Face center is logical UV `(0.50,0.48)`; relative to the bottom-center pivot it is `(0,-0.52*(416/1.55)*s)`. The whole 128×128 face canvas is drawn centered there at `0.45W` square. At W=80 CSS px it is 36×36 CSS px. Apply body rotation/squash to body and face together around that pivot; device-pixel ratio only affects backing resolution.
- Background: 576×1024 source; preserve aspect, keep scenery behind cats and use responsive crop/letterboxing. Floor top at source y=4 maps to world floor y=0. Source extents/alpha never define colliders.
- Studio clarified `decorativeBoundsPx=[44,32,468,353]` is `[xMin,yMin,xMax,yMax]`, equivalent xywh `[44,32,424,321]`: a conservative authored envelope including stroke, not measured painted/alpha extents. Treat as advisory; never use it for collision or automatic trim. Painted art must fit the canvas and the permitted envelope: ±0.10W horizontally, 0.25H above and 0.05H below the logical body. Readability, tucked-tail appearance and absence of misleading support shapes require visual evidence.
