## Runtime contracts

1. **Controller:** use the existing Engine API. Seed outside the engine; fix mode/skin per run. Drain/fan out each event batch once after ticks and synchronous lifecycle calls. Before replacing a run, drain old events, clear old input/effects, create a new run generation and drain new spawn events. Do not award score from presentation or results transitions. No listener/loop multiplication across Replay.
2. **Loop:** one requestAnimationFrame owner, fixed 1/60-second accumulator, at most five ticks/frame. A gap greater than250ms pauses immediately as `interrupted` and discards backlog. Discard excess over five ticks for smaller gaps. Pause/resume clears timestamp/accumulator. Hide, window blur and meaningful playfield size/orientation changes synchronously pause without waiting for a frame; show never auto-resumes. Initial sizing and identical ResizeObserver notifications must not create spurious pauses. Resize projection and render before explicit Resume. Freeze presentation clocks/camera while paused.
3. **Input:** follow04 input/focus rules exactly: primary canvas pointerdown, native Drop click, no compatibility-click duplication, right/secondary fingers ignored. Space/Enter only from focused play region, reject repeats; native buttons retain native activation. Assist arrows may repeat only while focused and aiming. Shared dispatcher captures run/spawn generation and never buffers into the next cat. Opening/closing/Resume/Replay gestures cannot become Drop. Escape pauses; Escape on Pause stays paused. Modal focus trap, background inertness, restore focus and fresh post-resume input required.
4. **Screens:** Home has mode choice, instruction and Start. Live DOM shows score, height, mode, chain>=2, named safety band, Pause and Drop; Assist adds Left/Right and signed offset/local-overlap/predicted-stability text. Compute Assist preview with prepareDrop/evaluatePlacement only on spawn/nudge; never infer global safety from local overlap. Disable gameplay outside AIMING; Pause remains available in every live phase. Pause offers Resume, Restart and Home; Restart/Home require confirmation, Cancel returns to Pause. Until M3, confirmation says “End this temporary round and start again?” / “End this temporary round and return home?” without promising saved progress. Collapse identifies missed top versus unstable tower and offers immediate Skip. Results shows final score/height and Replay/Change mode/Home; no fabricated best/unlock badges.
5. **Accessibility:** controls>=44px and Drop>=64px high, visible focus, canvas label plus DOM descriptions, polite event-driven announcements, no per-frame narration. Preserve browser zoom and menu scroll. Announce Assist nudge feedback at most once/300ms for held keys. Include canvas/context failure message and recoverable application error screen. No broader screen-reader conformance claim without a named-reader test.
6. **Projection:** reserve actual HUD/control space, worldWidth10; use03 cameraBottom/projection/short-landscape rules, dynamic viewport/safe-area CSS and shell scrolling when needed. Backing scale=min(DPR,2) further capped to2M pixels. Incoming aim x is current logical x, never extrapolated. Camera is vertical only and affects no gameplay. Cull settled cats analytically from the visible vertical index interval; do not scan/rebuild all historical cat objects per frame. Respect <=24 drawn settled cats and <=20 collapse bodies.
7. **Readable reactions:** implement idle/focused/falling-surprised/landed-happy/danger-worried/collapse-dizzy priorities from05, target guide, safety text/icon/outline and failure-joint cue. Presentation-only landing squash/wobble/collapse follow04 caps. No audio in M2; explicitly report silent reactions. Respect system reduced motion at start and remove decorative movement immediately when it changes. Engine collapse duration is start-time only until the already specified M4 hook; report that limitation rather than calling mid-collapse shortening passed. Skip remains available. Reduced motion uses immediate camera reposition between placements and static collapse feedback.
